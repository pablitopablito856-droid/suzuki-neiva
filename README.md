# Suzuki Neiva - Concesionario Oficial

Sitio web oficial y landing page comercial de **Suzuki Neiva** (Huila, Colombia). Diseñado para máxima conversión de clientes, cotizaciones directas por WhatsApp y optimizado para SEO Local en motores de búsqueda.

## 🚀 Características
- **Catálogo Interactivo:** Fichas técnicas completas, cambio de colores en tiempo real y cotizaciones dinámicas por WhatsApp.
- **Video Hero en Portada:** Reproducción automática en bucle de la Suzuki V-Strom 160.
- **Sección de Ubicación con Mapa:** Integración con Google Maps para llegar a la sede `Cl 4 #6-44, Centro, Neiva, Huila`.
- **Botones Flotantes de Contacto:** Llamada telefónica directa y WhatsApp con tooltip interactivo.
- **SEO Local & Schema.org (JSON-LD):** Configurado con datos estructurados de `MotorcycleDealer`, `FAQPage` y `BreadcrumbList`.
- **Sitemap & Robots:** Preparado para indexación en Google.

## 📌 Publicación en GitHub Pages

Para publicar este sitio web en GitHub Pages:

1. Crea un nuevo repositorio en [GitHub](https://github.com/new) (ej. `suzukineiva` o `sitio-suzuki-neiva`).
2. Abre la terminal en esta carpeta y ejecuta:
```bash
git init
git add .
git commit -m "Initial commit - Suzuki Neiva website"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
git push -u origin main
```
3. En tu repositorio de GitHub, ve a **Settings** > **Pages**.
4. En **Build and deployment > Source**, selecciona **Deploy from a branch**.
5. Elige la rama **`main`** y la carpeta **`/(root)`**, luego haz clic en **Save**.
6. ¡En unos segundos tu sitio estará en línea en `https://TU_USUARIO.github.io/TU_REPOSITORIO/`!
